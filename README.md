**Цель:** Анализ пользовательской воронки, из активности пользователя расчитать конверсии на каждом этапе для двух групп **control** и **pilot**. Группа **control** соответствует старому экрану оплаты, **pilot** новому.

**Задание 1:**  

Необходимо написать оптимальный запрос, который даст информацию о количестве очень усердных студентов. Назовём очень усердным учеником того пользователя, который хотя бы раз за текущий месяц правильно решил 20 горошин(задач).  

**Задание 2:**  

Необходимо в одном запросе выгрузить следующую информацию о группах пользователей:

атике
